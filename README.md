## `> whoami`

I'm **Le Hoang Long** (`@longurara`), a developer who enjoys exploring how software works under the hood — and turning that curiosity into projects people can actually use.

I work on everything from **C++ search utilities** and **offline-first web applications** to experiments in **bringing Unity experiences to the browser**. I'm especially interested in performance, developer tooling, cross-platform software, and learning by building.
